L01 — Vectors, Dot Products, and Similarity

How do we turn real objects into numbers, and then measure how similar they are?
  • Vectors — data as ordered lists of numbers [MASTER]
  • Dot product — agreement score [MASTER]
  • Norms — measuring size [MASTER: L2] [UNDERSTAND: L1]
  • Distance — how far apart [MASTER]
  • Cosine similarity — direction without magnitude [MASTER]

Remember Spotify?

In Unit 0 we saw: Spotify turns every song into a list of numbers, then finds songs whose numbers are "close" to yours.

Today we make that precise. What IS a "list of numbers"? What does "close" mean, exactly?
  • The list of numbers = a vector.
  • "Close" = small distance or high cosine similarity.
  • By the end of today, you can compute these by hand.
"Last time we said Spotify, Instagram, ChatGPT all do the same three steps: turn things into numbers, measure closeness, pick the closest. Today we build the math for steps 1 and 2. Step 1: vectors. Step 2: dot product, norms, distance, cosine. All of this is arithmetic you already know — add, multiply, square root. We're just giving names to patterns you've seen before."

Report cards for everything

In Unit 0, we gave every word a report card — a list of numbers describing its features.

The same idea works for anything:

  • A patient: (blood pressure, heart rate, temperature) = (120, 75, 98.6)
  • A song: (tempo, energy, danceability) = (0.8, 0.6, 0.9)
  • A student: (GPA, study hours, sleep hours) = (3.2, 5, 7)
Once everything is a list of numbers, we can use arithmetic to compare, measure, and transform.
"Last time we said 'cat' gets a report card: noun-ness 0.9, verb-ness 0.1, etc. Today: EVERYTHING gets a report card. A patient, a song, a movie, YOU. Your GPA, study hours, sleep hours — that's three numbers describing you as a student. AI does this to everything: take a real thing, turn it into numbers." Ask: "What three numbers would describe YOU as a student?"

Three movies walk into a bar...

Each movie is described by three features: action level, romance level, comedy level.

\[\text{Movie X} = (3, 1, 0) \qquad \text{Movie Y} = (6, 2, 0) \qquad \text{Movie Z} = (0, 1, 3)\]
  • X is a mild action movie. Y is a BIGGER action movie (same mix, double the intensity).
  • Z is a pure comedy — completely different taste.
Which two movies should Spotify-for-movies recommend together: X and Y, or X and Z?
"Imagine Netflix wants to recommend movies. It turns each movie into numbers. X is a mild action movie. Y is an intense action movie — same DNA, just louder. Z is a comedy — totally different DNA. Obviously X and Y go together. But how would a COMPUTER know that? It can't watch the movie. It can only look at numbers." This is the core challenge: making 'similarity' into arithmetic.

Now name it: vector

A vector in \(\R^d\) is an ordered list of \(d\) real numbers: \[\mathbf{x} = (x_1, x_2, \ldots, x_d)^\top.\] Convention: vectors are column vectors. The \({}^\top\) makes the row into a column.
  • In geometry: an arrow with direction and length.
  • In data science: a feature list describing one object.
  • \(d\) = number of features. ChatGPT uses \(d = 12{,}288\). We start with \(d = 2\) or \(3\).
Every AI system begins by converting real things into vectors. No vectors, no AI.
"Vector is just a fancy word for 'ordered list of numbers.' You've been making vectors your whole life — every time you fill out a form with multiple fields, that's a vector. Your college application: (GPA, SAT, extracurriculars) — that's a 3D vector. ChatGPT uses 12,288-dimensional vectors. Same idea, just longer lists."

Vector arithmetic: adding and scaling

Let \(\mathbf{x} = (2, -1)\) and \(\mathbf{y} = (-3, 4)\).

  • Addition: \(\mathbf{x} + \mathbf{y} = (2 + (-3),\; -1 + 4) = (-1, 3)\). Like combining two ingredient lists.
  • Scaling: \(2\mathbf{x} = (4, -2)\). Like doubling a recipe — same proportions, bigger batch.
All arithmetic is component by component.
"Adding vectors: just add matching entries. Like if you and your friend each bring groceries. You bring (2 apples, 3 oranges), they bring (1 apple, 5 oranges). Together: (3 apples, 8 oranges). Component by component." "Scaling: double everything. A recipe for 4 people → recipe for 8 people. Same proportions, just more."

Quick check: vectors

Compute \(2\mathbf{x} - \mathbf{y}\) for \(\mathbf{x} = (2, -1)\) and \(\mathbf{y} = (-3, 4)\).

Answer: \(2(2, -1) - (-3, 4) = (4, -2) - (-3, 4) = (7, -6)\).

This is the same arithmetic behind "weighted average" in your GPA calculation — scale each entry, then combine.
"Step by step: first scale x by 2, then subtract y. Each component independently. This is all vector arithmetic is — entry by entry. The power comes from doing it systematically on thousands of dimensions."

Measuring agreement: the key to similarity

Recall: \(\text{Movie X} = (3, 1, 0)\), \(\text{Movie Y} = (6, 2, 0)\), \(\text{Movie Z} = (0, 1, 3)\).

Three numbers each. How do we get a single number that says "how similar are they"?
  • Idea: multiply matching features and add them up.
  • If both movies score high on the same feature → big positive product.
  • If they disagree → products cancel out.

This "agreement score" has a name: the dot product.

"Think of it like this: you and your friend both rate 3 categories. If you both give action a high score, multiplying them gives a big positive number. If you love action but your friend hates it — one positive, one negative — the product is negative. Add up all three products and you get an 'agreement score.' That's ALL the dot product is."

Worked example: similar movies

Movie X = (3, 1, 0) and Movie Y = (6, 2, 0). Both are action-heavy.

\[\mathbf{x}^\top \mathbf{y} = 3 \times 6 + 1 \times 2 + 0 \times 0 = 18 + 2 + 0 = 20.\]
Score = 20. Large positive number = strong agreement. These movies have similar DNA.

Now the different movie: X = (3, 1, 0) and Z = (0, 1, 3).

\[\mathbf{x}^\top \mathbf{z} = 3 \times 0 + 1 \times 1 + 0 \times 3 = 0 + 1 + 0 = 1.\]

Score = 1. Much smaller. Almost no agreement.

"X and Y agree on action (3×6=18), agree on romance (1×2=2), and both ignore comedy (0×0=0). Total: 20. Strong agreement." "X and Z: action doesn't match (3×0=0), slight romance overlap (1×1=1), comedy doesn't match (0×3=0). Total: 1. Almost strangers." "The dot product QUANTIFIED what your intuition already knew: X and Y are similar, X and Z are not."

Now name it: dot product

The dot product of \(\mathbf{x}, \mathbf{y} \in \R^d\): \[\mathbf{x} \cdot \mathbf{y} = x_1 y_1 + x_2 y_2 + \cdots + x_d y_d = \sum_{i=1}^d x_i y_i.\]
  • Multiply matching entries. Add the products. Get one number.
  • Notation: since our vectors are column vectors, the dot product equals \(\mathbf{x}^\top \mathbf{y}\) — transpose the first, then multiply. We use \(\mathbf{x}^\top \mathbf{y}\) from now on.
  • This is exactly the same operation inside the attention formula: \(QK^\top\).
When ChatGPT asks "how related is this word to that word?" — it computes a dot product.
"The dot product literally used to be written with a dot: x · y. We write x^T y instead because our convention is that vectors are columns. Transposing x makes it a row, then row × column = a single number. Same operation, just matrix notation. From now on, x^T y means dot product." "QK^T is a matrix of dot products — each entry asks 'how related is word i to word j?'"

What does the sign tell you?

  • Positive: similar direction. Agreement.
  • Zero: perpendicular. Unrelated.
  • Negative: opposing. Disagreement.
In recommendation: positive = "these items go together." Negative = "these items repel each other." Zero = "no relationship."
"Think of it like two people's opinions. Positive dot product: 'We agree!' Zero: 'We have nothing in common.' Negative: 'We disagree on everything.' In AI, the sign tells the model whether two things should be grouped together or kept apart."

Worked example: student preferences

Two students rate 3 features of their ideal college: (campus size, city feel, sports).

Alice = (2, 5, 1). Bob = (4, 3, 2). Carmen = (-1, 5, 0).

  • Alice \(\cdot\) Bob: \(2(4) + 5(3) + 1(2) = 8 + 15 + 2 = 25\). Positive — similar tastes.
  • Alice \(\cdot\) Carmen: \(2(-1) + 5(5) + 1(0) = -2 + 25 + 0 = 23\). Also positive — they agree on city feel.
Your turn: compute Bob \(\cdot\) Carmen.

Answer: \(4(-1) + 3(5) + 2(0) = -4 + 15 + 0 = 11\). Moderate agreement.

"Notice: even though Carmen has a NEGATIVE score for campus size, the dot product with Alice is still positive because they strongly agree on city feel (5×5=25 dominates). The dot product captures overall agreement, not just one feature."

Quick check: dot product

Compute \((1, 2, 0)^\top (3, -1, 4)\). What does the sign tell you?

Answer: \(1 \cdot 3 + 2 \cdot (-1) + 0 \cdot 4 = 3 - 2 + 0 = 1\). Positive: mild agreement.

"The result is 1 — barely positive. These vectors mildly agree but aren't strongly aligned. Like two acquaintances who have one hobby in common."

How big is the error?

Your GPS says you'll arrive in 25 minutes. You actually arrive in 30.

The error is 5 minutes. Easy with one number. But what if you have HUNDREDS of predictions?
  • A model predicts exam scores for 3 students: \(\hat{\mathbf{y}} = (85, 90, 70)\).
  • Actual scores: \(\mathbf{y} = (80, 92, 75)\).
  • Error vector: \(\mathbf{e} = (5, -2, -5)\). Three errors. We need ONE number.
AI training is ALL about making this number smaller. But first: how do we measure the "size" of a vector?
"When AI trains, it makes thousands of predictions, each slightly wrong. The errors form a vector. Training = make this vector SMALLER. But what does 'smaller' mean for a vector? We can't just add the entries — positive and negative errors would cancel! We need a way to measure the LENGTH of the error vector."

The Pythagorean way: L2 norm

You know the Pythagorean theorem: for a right triangle with sides 3 and 4, the hypotenuse is 5.

\[\sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5.\]

The \(\ell_2\) norm is the same idea applied to any vector:

For \(\mathbf{x} = (3, 4)\): \(\norm{\mathbf{x}}_2 = \sqrt{3^2 + 4^2} = 5.\)

The \(\ell_2\) norm = straight-line distance from the origin. Like measuring with a ruler.
"You already know this! The Pythagorean theorem from high school. a² + b² = c². The L2 norm is just Pythagoras generalized to any number of dimensions. For a 3D vector (a, b, c), it's √(a² + b² + c²). For 768 dimensions, same idea — just a longer sum under the square root."

The city-block way: L1 norm

In Manhattan, you can't walk diagonally. You walk 3 blocks east, then 4 blocks north. Total: 7 blocks.

The \(\ell_1\) norm adds absolute values:

For \(\mathbf{u} = (-2, 5)\): \(\norm{\mathbf{u}}_1 = |-2| + |5| = 2 + 5 = 7.\)

  • \(\ell_2\) (Pythagoras): straight-line distance = \(\sqrt{4 + 25} = \sqrt{29} \approx 5.4\).
  • \(\ell_1\) (Manhattan): walk along grid lines = \(7\).
Same vector, two ways to measure "how big." Each is useful in different AI applications.
"Why two norms? L2 penalizes big errors more (because of squaring). L1 treats every error equally. In machine learning, choosing L1 vs L2 changes what your model learns — L1 tends to zero out small features (sparsity), L2 spreads the error around. We'll see this again when we study regularization."

Now name them: norms

\[\norm{\mathbf{x}}_2 = \sqrt{\sum_{i=1}^d x_i^2}, \qquad \norm{\mathbf{x}}_1 = \sum_{i=1}^d |x_i|.\]
  • \(\ell_2\) penalizes large entries harshly (squaring). One big error dominates.
  • \(\ell_1\) treats all entries equally (absolute value). Many small errors add up.
AI training uses \(\ell_2\) (MSE loss) or \(\ell_1\) (MAE loss) to measure prediction quality.
"MSE = Mean Squared Error = average of squared errors. That's L2 norm squared, divided by n. MAE = Mean Absolute Error = average of absolute errors. That's L1 norm divided by n. When you see 'loss function' in AI — it's usually one of these norms in disguise."

L1 vs L2: different geometry

The "unit ball" — all vectors with norm \(\le 1\) — looks different for each norm:

  • \(\ell_2\) ball: a circle (all points at distance 1 from origin).
  • \(\ell_1\) ball: a diamond (corners on the axes).
The diamond shape of the \(\ell_1\) ball is why L1 regularization pushes weights to exactly zero — the corners are on the axes.
"You don't need to understand regularization yet. But file this picture away. In Week 9, when we discuss how AI prevents overfitting, we'll come back to these shapes and the diamond's corners will be the key insight."

Quick check: norms

Compute \(\norm{(3, -4)}_2\) and \(\norm{(3, -4)}_1\).

Answer: \(\norm{(3, -4)}_2 = \sqrt{9 + 16} = 5\). \(\norm{(3, -4)}_1 = 3 + 4 = 7\).

Notice: \(\ell_2 \le \ell_1\) always. The straight line is never longer than the city blocks.

"3-4-5 right triangle — the most famous Pythagorean triple. The L2 norm is 5, the hypotenuse. The L1 norm is 7, walking along the two legs. The direct path is always shorter than the grid path."

Finding the closest match

Spotify has 100 million songs, each described by a vector. You just liked a song.

Spotify's job: find the song whose vector is closest to the one you liked.
  • We know how to measure the size of ONE vector (norms).
  • Distance between two vectors = size of their difference.
Nearest-neighbor search is behind recommendation, image search, and even ChatGPT's retrieval system.
"This is literally what recommendation systems do. Every song is a point in number-space. Your favorite song is one point. Spotify calculates the distance from your point to every other point, then plays the closest ones. The math: subtract the two vectors, measure the length of the difference."

Worked example: how far apart?

Two data points: \(\mathbf{x} = (1, 2)\) and \(\mathbf{y} = (4, 6)\).

Step 1 — find the difference: \(\mathbf{x} - \mathbf{y} = (1 - 4,\; 2 - 6) = (-3, -4)\).

Step 2 — measure the length: \(\norm{(-3, -4)}_2 = \sqrt{9 + 16} = 5.\)

\[d(\mathbf{x}, \mathbf{y}) = \norm{\mathbf{x} - \mathbf{y}}_2 = 5.\]
Distance = the norm of the difference. Subtract, then measure.
"Two steps: subtract, then Pythagoras. That's it. The distance between two points = the length of the arrow connecting them. In AI, when we say 'these two items are close,' we mean this number is small."

Now name it: distance

\[d(\mathbf{x}, \mathbf{y}) = \norm{\mathbf{x} - \mathbf{y}}_2 = \sqrt{\sum_{i=1}^d (x_i - y_i)^2}.\]
  • Always \(\ge 0\). Equals \(0\) only when \(\mathbf{x} = \mathbf{y}\) (same point).
  • Symmetric: distance from A to B = distance from B to A.
  • Triangle inequality: the direct path is never longer than a detour.
"These three properties are what make it a 'true' distance. Any function with these three properties is called a metric. Different norms give different distances — L1 distance is the city-block distance, L2 is the straight-line distance."

A common mistake

Is "difference of lengths" the same as "length of difference"?

Let \(\mathbf{x} = (1, 2)\) and \(\mathbf{y} = (4, 6)\).

  • Difference of lengths: \(\norm{\mathbf{x}}_2 - \norm{\mathbf{y}}_2 \approx 2.24 - 7.21 \approx -4.97\).
  • Length of difference: \(\norm{\mathbf{x} - \mathbf{y}}_2 = \norm{(-3, -4)}_2 = 5\).
Not the same! You cannot distribute the norm over subtraction. This is a common exam mistake.
"The norm is NOT linear. You can't pull the subtraction outside the norm. This trips up students every semester. Write it in big letters: ||x - y|| ≠ ||x|| - ||y||. Think of it this way: two people can be the same height (same norm) but stand far apart (large distance)."

Same taste, different intensity

Two people rate movies on a scale of 0-10:

  • You: (8, 2, 0) — love action, meh on romance, hate comedy.
  • Your friend: (4, 1, 0) — same preferences, but rates everything lower.
You have the same taste. But Euclidean distance says you're far apart. What went wrong?
  • Distance measures size. But taste is about direction.
  • We need a measure that ignores magnitude and captures direction only.
"Imagine a harsh critic who gives every movie a 2. And a generous critic who gives the same movies an 8. They AGREE on which movies are good and which are bad — they just use different scales. Euclidean distance says they're far apart. But a recommendation system should treat them as identical. Cosine similarity does exactly that."

Worked example: three steps

Let \(\mathbf{x} = (1, 2)\) and \(\mathbf{y} = (3, -1)\). How similar is their direction?

Step 1 — Dot product (numerator):

\[\mathbf{x}^\top \mathbf{y} = 1(3) + 2(-1) = 3 - 2 = 1.\]

Step 2 — Norms (denominator):

\[\norm{\mathbf{x}}_2 = \sqrt{1 + 4} = \sqrt{5}, \qquad \norm{\mathbf{y}}_2 = \sqrt{9 + 1} = \sqrt{10}.\]

Step 3 — Divide:

\[\cos\theta = \frac{1}{\sqrt{5} \cdot \sqrt{10}} = \frac{1}{\sqrt{50}} \approx 0.14.\]

Small positive value = mild directional agreement. They point in roughly the same direction.

"Three steps: dot product on top, product of norms on bottom. The denominator normalizes away the lengths, so you're only measuring the angle. Result is always between -1 and 1."

Now name it: cosine similarity

\[\cos\theta = \frac{\mathbf{x}^\top \mathbf{y}}{\norm{\mathbf{x}}_2 \, \norm{\mathbf{y}}_2}\]
ValueMeaningExample
\(\cos\theta = 1\)Same directionTwo action fans (different intensity)
\(\cos\theta = 0\)PerpendicularAction fan vs. someone who only cares about comedy
\(\cos\theta = -1\)Opposite directionOne loves what the other hates
Google Search ranks pages by cosine similarity between your query vector and each page's vector.
"When you Google something, the search engine turns your query into a vector and every web page into a vector. It computes cosine similarity between your query and each page. Highest cosine = best match. That's why a search for 'best pizza near me' returns pizza reviews, not sushi restaurants — high cosine similarity."

Why this works: unit vectors

Dividing by the norm shrinks any vector to length 1:

\[\hat{\mathbf{x}} = \frac{\mathbf{x}}{\norm{\mathbf{x}}_2}\]
  • \(\hat{\mathbf{x}}\) points in the same direction as \(\mathbf{x}\), but has length exactly 1.
  • Cosine similarity = dot product of unit vectors: \(\cos\theta = \hat{\mathbf{x}}^\top \hat{\mathbf{y}}\).
This is why your harsh-critic and generous-critic friends get the same cosine score — after normalizing, their vectors are identical.
"Normalizing = shrinking to length 1. It removes magnitude and keeps only direction. Like converting a recipe from '4 cups flour, 2 cups sugar' to '2 parts flour, 1 part sugar' — the proportions are what matter, not the absolute amounts."

Quick check: cosine similarity

If \(\mathbf{y} = 5\mathbf{x}\) for some nonzero \(\mathbf{x}\), what is \(\cos\theta\)?

Answer: \(\cos\theta = 1\). Scaling does not change the angle.

Follow-up: If \(\mathbf{y} = -3\mathbf{x}\), what is \(\cos\theta\)?

Answer: \(\cos\theta = -1\). Flipping direction gives the exact opposite.

"If y is just a scaled-up version of x, they point the same way → cosine = 1. If y is a negative multiple of x, they point in opposite directions → cosine = -1. Cosine is BLIND to magnitude. That's its superpower for recommendation and search."

L02 — Matrices: Transformation Machines

How does a model transform inputs into predictions — all at once?
  • Matrix as data table [MASTER]
  • Matrix-vector multiplication = batch prediction [MASTER]
  • Linear maps — what "linear" means geometrically [UNDERSTAND]
  • Matrix-matrix multiplication = chaining transformations [MASTER]

From one prediction to many

Last time we computed a dot product: one student's features \(\cdot\) model weights = one prediction.

But a class has 30 students. A dataset has millions of rows. How do we predict ALL of them at once?
  • We could compute 30 separate dot products...
  • Or we could organize the data into a table and multiply once.
  • That table has a name: a matrix.
"Last class: one student, two features, one dot product, one prediction. But what if you're a professor with 30 students? You don't want to do 30 separate calculations. You want to run them all at once. That's exactly what matrix-vector multiplication does — it's a batch dot product."

Start with a data table

Three students, two features each: hours studied and hours slept before the exam.

\[\begin{bmatrix} 5 & 7\\ 3 & 8\\ 6 & 6 \end{bmatrix}\]
  • Each row is one student (one data point).
  • Each column is one feature (one measurement).
This is how EVERY dataset looks: rows = observations, columns = features. Exactly like a spreadsheet.
"You've seen this format before — it's a spreadsheet. Every dataset in data science is a table like this. The only new thing: we're going to do MATH on the whole table at once, not one cell at a time."

Now name it: matrix

A matrix \(A = [a_{ij}] \in \R^{m \times n}\) has \(m\) rows and \(n\) columns.

The entry in row \(i\), column \(j\) is \(a_{ij}\).

Think of \(a_{ij}\) as a spreadsheet cell address: row \(i\), column \(j\).

\[A = \begin{bmatrix} 1 & 2 \\ -1 & 3 \end{bmatrix} \quad \Rightarrow \quad a_{12} = 2, \quad a_{21} = -1.\]

Common mistake: swapping row and column — \(a_{12}\) is row 1, column 2, not the other way.

"a_{ij}: first index = row, second = column. Like a street address: avenue first, then street. Students confuse this every year. a_{12} means row 1, column 2. NOT row 2, column 1. Drill it: row first, column second."

Two special operations

Transpose \(A^\top\): swap rows and columns. \((A^\top)_{ij} = a_{ji}\).

\[A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix} \;\Longrightarrow\; A^\top = \begin{bmatrix} 1 & 3 \\ 2 & 4 \end{bmatrix}\]

Identity matrix \(I\): the "do nothing" matrix. \(I\mathbf{x} = \mathbf{x}\) for any \(\mathbf{x}\).

\[I = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}, \qquad I \begin{bmatrix} 3 \\ 7 \end{bmatrix} = \begin{bmatrix} 3 \\ 7 \end{bmatrix}.\]
The identity matrix is like multiplying by 1 — it will show up as the "starting point" in many AI algorithms.
"Transpose: flip the table on its diagonal. Rows become columns and vice versa. If A is 2×3, then A^T is 3×2." "Identity: 1's on the diagonal, 0's everywhere else. It's the matrix version of the number 1 — multiplying by it does nothing. When an AI model starts training, its weights often begin near the identity."

Quick check: matrices

If \(A \in \R^{2 \times 3}\), how many entries does \(A\) have? What is the shape of \(A^\top\)?

Answer: \(2 \times 3 = 6\) entries. \(A^\top \in \R^{3 \times 2}\).

"2 rows × 3 columns = 6 entries total. Transpose swaps the dimensions: 2×3 becomes 3×2."

The real question: batch prediction

A student has features (hours studied, hours slept) = \((5, 7)\). The model assigns weights \((0.6, 0.4)\). Predicted score?
\[0.6 \times 5 + 0.4 \times 7 = 3.0 + 2.8 = 5.8.\]

That's a dot product! One student, one prediction.

Now imagine 1,000 students. We want 1,000 predictions — all at once.
"One student, two features, one dot product, one prediction. You already know how to do this from last class. But a real dataset has thousands of rows. We need to run the SAME dot product on every row. That's matrix-vector multiplication."

Three students at once

\[X = \begin{bmatrix} 1 & 2\\ 2 & 1\\ 3 & 4 \end{bmatrix}, \qquad \mathbf{w} = \begin{bmatrix} 2\\ 1 \end{bmatrix}.\]

Each row of \(X\) is one student. \(\mathbf{w}\) is the weight vector.

\[X\mathbf{w} = \begin{bmatrix} 1(2) + 2(1)\\ 2(2) + 1(1)\\ 3(2) + 4(1) \end{bmatrix} = \begin{bmatrix} 4\\ 5\\ 10 \end{bmatrix}.\]
One operation. Three predictions. Each output is a dot product of one row with \(\mathbf{w}\).
"Row 1 dot w = 1×2 + 2×1 = 4. Row 2 dot w = 2×2 + 1×1 = 5. Row 3 dot w = 3×2 + 4×1 = 10. Three dot products, but we write it as ONE matrix-vector product. That's the power: one notation for 3 (or 3 million) predictions."

Now name it: matrix-vector multiplication

For \(A \in \R^{m \times n}\) and \(\mathbf{x} \in \R^n\): \[(A\mathbf{x})_i = \sum_{j=1}^n a_{ij} x_j.\]
  • Each output entry = dot product of row \(i\) with \(\mathbf{x}\).
  • Dimensions: \(A \in \R^{m \times n}\), \(\mathbf{x} \in \R^n\) \(\Rightarrow\) \(A\mathbf{x} \in \R^m\). Input has \(n\) entries, output has \(m\).
In AI: \(A\) = model weights, \(\mathbf{x}\) = input features, \(A\mathbf{x}\) = predictions. This is a linear model.
"The formal definition looks dense but it's saying: for each row, take the dot product with x. That's it. The dimension rule is crucial: the number of COLUMNS in A must equal the number of ENTRIES in x. Otherwise the dot products don't work — you'd be multiplying mismatched lists."

Worked example 2

\[A = \begin{bmatrix} 1 & 2 \\ -1 & 3 \end{bmatrix}, \quad \mathbf{x} = \begin{bmatrix} 2 \\ -1 \end{bmatrix}.\]
  • Row 1: \(1(2) + 2(-1) = 2 - 2 = 0\).
  • Row 2: \((-1)(2) + 3(-1) = -2 - 3 = -5\).
  • \(A\mathbf{x} = \begin{bmatrix} 0 \\ -5 \end{bmatrix}\). The matrix turned \((2, -1)\) into \((0, -5)\).
The matrix moved the vector. It transformed it. That's what matrices DO — they are transformation machines.
"Look at what happened: we put in (2, -1) and got out (0, -5). The matrix MOVED the point. Different matrices move points differently — some stretch, some rotate, some flip. That's the key insight: a matrix is not just a table of numbers. It's a MACHINE that transforms vectors."

Another way to see it: column view

There's a second way to read \(A\mathbf{x}\): as a weighted combination of columns.

\[2 \begin{bmatrix} 1 \\ -1 \end{bmatrix} + (-1) \begin{bmatrix} 2 \\ 3 \end{bmatrix} = \begin{bmatrix} 2 \\ -2 \end{bmatrix} + \begin{bmatrix} -2 \\ -3 \end{bmatrix} = \begin{bmatrix} 0 \\ -5 \end{bmatrix}.\]
\(A\mathbf{x}\) = take the columns of \(A\), scale them by the entries of \(\mathbf{x}\), add them up. This is a linear combination.
"Row view: each output entry is a dot product. Column view: the output is a mix of the columns of A, with weights from x. Same answer, different perspective. The column view will become essential when we study linear combinations and span in the next unit."

Quick check: matrix-vector

Compute \(A\mathbf{x}\) for \(A = \begin{bmatrix} 2 & 0 \\ 1 & 3 \end{bmatrix}\) and \(\mathbf{x} = \begin{bmatrix} 1 \\ 2 \end{bmatrix}\).

Answer: \(A\mathbf{x} = \begin{bmatrix} 2(1) + 0(2) \\ 1(1) + 3(2) \end{bmatrix} = \begin{bmatrix} 2 \\ 7 \end{bmatrix}\).

"Row 1: 2×1 + 0×2 = 2. Row 2: 1×1 + 3×2 = 7. Quick sanity check: A is 2×2, x is 2×1, so Ax is 2×1. Dimensions match."

What does a matrix do to a picture?

If we apply \(A\mathbf{x}\) to every point in a grid, what happens to the grid?
  • Lines stay as lines (they do not curve).
  • The origin stays fixed.
  • The grid can stretch, rotate, reflect, or shear — but never bend.
This is like an Instagram filter that can resize, rotate, and flip your photo — but can't warp or distort curves.
"Imagine a grid of points, like graph paper. Apply a matrix to every point. The grid might stretch like taffy, rotate like a wheel, or flip like a mirror — but the lines always stay straight and the origin never moves. That's a linear transformation." "Why does AI care? Because a linear model can only learn straight-line relationships. If the real pattern is curved, we need more tools (which we'll build in later units)."

Grid transformation

A matrix can stretch, rotate, reflect, or shear — but always keeps lines straight.
"This is the key visual. Before: a nice square grid. After: the grid is deformed — stretched, rotated, maybe sheared — but every line is still a line. No curves. That's what 'linear' means geometrically."

What makes it "linear"?

A linear map \(\Phi\) satisfies two rules:

  • Additivity: \(\Phi(\mathbf{x} + \mathbf{y}) = \Phi(\mathbf{x}) + \Phi(\mathbf{y})\). Transform the sum = sum of transforms.
  • Scaling: \(\Phi(\alpha \mathbf{x}) = \alpha \Phi(\mathbf{x})\). Transform the scaled = scale the transform.
Every matrix \(A\) defines a linear map via \(\mathbf{x} \mapsto A\mathbf{x}\). Linear models in data science — regression, PCA, attention — all use this structure.
"These two rules say: it doesn't matter whether you combine first and then transform, or transform first and then combine — you get the same answer. That's linearity. It's a very special property, and it's the reason linear algebra is so powerful — it makes EVERYTHING predictable."

Chaining transformations

What if we apply one transformation and then another? Can we combine them into a single matrix?
  • First transform: rotate the grid (matrix \(B\)).
  • Then transform: stretch the grid (matrix \(A\)).
  • Combined: one matrix \(C = AB\) does both at once.
Neural networks are exactly this: layer after layer of matrix multiplications, each transforming the data further.
"A neural network with 100 layers does 100 matrix multiplications in sequence. Each layer transforms the data a little. Matrix-matrix multiplication lets us compose transformations — chain them together. Understanding this is understanding the backbone of deep learning."

Worked example: composing two transformations

\[A = \begin{bmatrix} 1 & 2 \\ -1 & 3 \end{bmatrix}, \quad B = \begin{bmatrix} 0 & 1 \\ 4 & -2 \end{bmatrix}.\]

We want \(C = AB\): first apply \(B\), then apply \(A\). Compute each entry:

  • \(c_{11} = 1(0) + 2(4) = 8\). \(\quad c_{12} = 1(1) + 2(-2) = -3\).
  • \(c_{21} = (-1)(0) + 3(4) = 12\). \(\quad c_{22} = (-1)(1) + 3(-2) = -7\).
\[AB = \begin{bmatrix} 8 & -3 \\ 12 & -7 \end{bmatrix}.\]
"Each entry is a dot product: row i of A with column k of B. That's 4 dot products for a 2×2 result. For bigger matrices: a 100×100 times a 100×100 means 10,000 dot products. GPUs do this in milliseconds."

Now name it: matrix multiplication

For \(A \in \R^{m \times n}\) and \(B \in \R^{n \times p}\): \[(AB)_{ik} = \sum_{j=1}^n a_{ij} b_{jk}.\]
  • Each entry of \(AB\) = dot product: row \(i\) of \(A\) with column \(k\) of \(B\).
  • Dimensions: \(\R^{m \times n} \cdot \R^{n \times p} \Rightarrow \R^{m \times p}\). The inner \(n\)'s must match.
"The pattern: row from A, column from B, dot product gives one entry. The dimension rule: inner dimensions must match. A is m×n, B is n×p. The n's match, so the product is m×p. If they don't match, multiplication is not defined."

Order matters!

Is \(AB = BA\)?
  • Generally no. Matrix multiplication is NOT commutative.
  • "Rotate then stretch" gives a different result than "stretch then rotate."
  • Sometimes \(BA\) doesn't even exist! (dimensions might not match.)
In neural networks: changing the order of layers changes the model. The sequence matters.
"This surprises students who are used to numbers: 3×5 = 5×3. But matrices are not numbers — they are TRANSFORMATIONS. And the order of transformations matters. Try it with real life: putting on socks then shoes gives a different result than shoes then socks."

Quick check: matrix multiplication

If \(A\) is \(2 \times 3\) and \(B\) is \(3 \times 4\), what is the shape of \(AB\)? Can you compute \(BA\)?

Answer: \(AB \in \R^{2 \times 4}\). Inner dimensions \(3 = 3\) match.

\(BA\): \(B\) is \(3 \times 4\), \(A\) is \(2 \times 3\). Inner dimensions \(4 \ne 2\). Not defined.

"AB works: 2×3 times 3×4 → inner 3's match → result is 2×4. BA fails: 3×4 times 2×3 → inner 4 ≠ 2 → can't multiply. Another reason AB ≠ BA: sometimes one exists and the other doesn't!"

The prediction pipeline

How does matrix-vector multiplication look in a real prediction pipeline?
Data matrix \(X \in \R^{n \times d}\), weight vector \(\mathbf{w} \in \R^d\), predictions \(X\mathbf{w} \in \R^n\).
  • \(n\) = number of samples (rows). One per student/patient/song.
  • \(d\) = number of features (columns). One per measurement.
This is the simplest AI model: linear regression. One matrix multiplication = all predictions at once.
"This is the template for ALL linear models. X is your dataset — n rows, d features. w is what the model learns — d weights. Xw gives n predictions, one per data point. Training = finding the best w. We'll learn how in Units 3-5."

Worked example: three data points

\[X = \begin{bmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2 \end{bmatrix}, \quad \mathbf{w} = \begin{bmatrix} 2 \\ -1 \end{bmatrix}.\]
  • Row 1: \(1(2) + 0(-1) = 2\).
  • Row 2: \(1(2) + 1(-1) = 1\).
  • Row 3: \(1(2) + 2(-1) = 0\).
  • \(X\mathbf{w} = \begin{bmatrix} 2 \\ 1 \\ 0 \end{bmatrix}\): three predictions, decreasing as feature 2 increases.
"Weight w_1 = 2 (positive: feature 1 helps). Weight w_2 = -1 (negative: feature 2 hurts). As feature 2 increases (0 → 1 → 2), the prediction drops (2 → 1 → 0). The model learned that feature 2 has a negative effect."

The dimension check habit

Before computing, always check: do the inner dimensions match?
\[\underbrace{X}_{n \times d} \; \underbrace{\mathbf{w}}_{d \times 1} = \underbrace{X\mathbf{w}}_{n \times 1}.\]

If the inner \(d\)'s do not match, the multiplication is not defined.

If \(X \in \R^{5 \times 3}\) and \(\mathbf{w} \in \R^{3}\), what is the shape of \(X\mathbf{w}\)? How many predictions?

Answer: \(X\mathbf{w} \in \R^5\). Five predictions, one per sample.

"This is the #1 debugging skill in data science. When your code crashes with 'dimension mismatch,' it means the inner dimensions don't agree. Before you compute anything, write down the shapes and check: do the inner numbers match? Get into this habit NOW — it will save you hours of debugging."
